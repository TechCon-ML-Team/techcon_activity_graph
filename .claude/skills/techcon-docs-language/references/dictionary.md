# словарь замен (полный)

Уровень `translate` — переводить везде, кроме технического слоя. Уровень `transliterate_ok` —
допустимо в коде, runbook и документации разработчика, запрещено у пользователя и в
управленческом тексте.

| плохо | хорошо | уровень |
|---|---|---|
| деплой, задеплоить, деплоить | выкатка, выкатить | translate |
| роллбэк, откатить деплой | откат, вернуть прежнюю версию | translate |
| фикс, пофиксить, зафиксить | исправление, исправить | translate |
| ишью, тикет | задача | translate |
| мерж, смёржить, замержить | слияние, слить | translate |
| пул-реквест | запрос на слияние | translate |
| релиз | выпуск | translate |
| билд | сборка | translate |
| автоскейлинг | автоматическое добавление машин | translate |
| хелсчек | проверка живости | translate |
| дрейф | расхождение | translate |
| ретрай | повтор | translate |
| бэкап | резервная копия | translate |
| секрет (пароль, ключ) | ключ доступа | translate |
| митигация | временная мера | translate |
| рут-кауз | первопричина | translate |
| постмортем | разбор | translate |
| перформанс | быстродействие | translate |
| легаси | устаревший код | translate |
| пейлоад | тело запроса | translate |
| воркер | обработчик | transliterate_ok |
| таймаут | превышение времени ожидания | transliterate_ok |
| эндпоинт | эндпоинт | transliterate_ok |

Слово «драйв» в значении «вести, управлять» не путать с «дрейф».

Калькам вне словаря тоже давай русскую замену: имплементировать → реализовать, инстанс →
экземпляр, кастомный → настраиваемый, апрувить → согласовывать, дебажить → отлаживать,
хендлить → обрабатывать, коннект → соединение, рендерить → отрисовывать.

Не трогать (устоялись): API, JSON, webhook, HTTP(S), URL, ID, токен, SDK, CLI, UUID, cron.

Код и литералы в обратных кавычках проверка языка не судит.
