# Развёрнутый итог сессии

Используется, когда трёх строк мало. Размер — не больше 60 строк. Разделы без содержания
пропускай, а не заполняй пустыми фразами.

```
Сделал / Проверил / Осталось — три строки, как в SKILL.md

Что нашли
  <тема>: факт, факт, вывод одной строкой

Что решили и почему
  выбрали X, а не Y, потому что …  (только нетривиальные выборы)

Что нужно сделать человеку
  - <действие> — почему это не может сделать агент (права, деньги, решение)

Открытые вопросы
  - <вопрос> → варианты и рекомендация

С чего начать следующую сессию
  ждём: …; проверить первым: …; не трогать: …
```

## Частые ошибки

- Хронология вместо выводов: «сначала сделал А, потом Б». Читателю нужен результат.
- Раздел «Что нужно сделать человеку» забит тем, что агент сделал бы сам.
- Итог длиннее работы: если сессия была короткой, хватит трёх строк.
- Итог переписан заново при каждой правке: держи один актуальный экземпляр, а не пачку.
