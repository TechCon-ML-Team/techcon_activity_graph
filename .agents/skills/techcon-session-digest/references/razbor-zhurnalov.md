# Разбор журналов сессий: команды и подводные камни

Каталог проектов Claude Code находится в домашней папке пользователя, в подкаталоге
`.claude/projects/`. Имя вложенного каталога — путь рабочего каталога сессии, где «/»
заменён на «-».

## Найти сессию

- по проекту и дате: `ls -lt <каталог проекта> | head -20` — сортировка по времени
  изменения файла; у старой сессии, которую что-то трогало позже, время обманчиво,
  поэтому сверяй с датой внутри записей;
- по теме: `grep -l "<характерная фраза>" <каталог проекта>/*.jsonl`.

## Восстановить ход

Журнал — построчный JSON: одна запись на реплику, вызов инструмента или его результат.
Разбирай `jq` по типу записи; у записей есть отметка времени и признак, кому они
принадлежат (главный агент или субагент). Субагенты пишут в подкаталог рядом с журналом.

## Подводные камни

- Крупные результаты инструментов вынесены в отдельные файлы рядом с журналом; в основной
  записи остаётся только ссылка — без них видна лишь верхушка вывода.
- После сжатия контекста ранняя часть сессии остаётся в журнале, но модель её уже не
  видела: итог по «памяти» сессии будет неполным, итог по журналу — полным.
- Журнал содержит всё, что печатали команды, включая секреты. Не выводи записи целиком;
  фильтруй по нужному полю и не цитируй значения.
- Учёт токенов есть не во всех записях. Если у части сообщений его нет, стоимость — «не
  менее», а не точное число.
- Время в журнале — в UTC; переводи в местное явно.
