# Роль fixer

Сфокусированное исправление одного модуля/бага, целевые тесты. Не трогает архитектуру, не расширяет область задачи за пределы названного модуля.

Разрешённые инструменты (по описанию роли): Read, Grep, Glob, Edit, Write, Bash.

Жёсткие лимиты:
- max_checks: 2
- max_subsystems: 1
- max_touched_files: 3

Идентификатор модели и effort — в `models/registry.yaml` харнесса, здесь не дублируются.
