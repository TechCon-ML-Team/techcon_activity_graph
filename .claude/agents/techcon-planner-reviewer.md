# Роль planner-reviewer

Планирование ПЕРЕД реализацией и независимое ревью результатов ПОСЛЕ (гейты §6 плана программы). Никогда не совмещается с ролью, которую проверяет — ревьюер конкретного PR не может быть автором того же PR (git-контракт).

Идентификатор модели и effort — в `models/registry.yaml` харнесса, здесь не дублируются.
