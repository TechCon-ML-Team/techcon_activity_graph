# Вёрстка и выпуск

## Данные и сборщик

- Файл данных лежит рядом с версией, с записями чисел (значение, единица, знаменатель,
  источник, дата среза). Схема данных проверяется сборщиком; запись без поля — ошибка сборки,
  а не пустая ячейка.
- Сборщик читает только файл данных. Чтение живых систем — отдельный шаг до сборки, его
  результат сохраняется в файл данных с датой замера.
- Детерминированность: сортировка ключей, фиксированные локаль и часовой пояс, дата из
  данных, никакого `now()` в тексте.

## Версии

- Имя: `<название>-<дата>.html` (и при нескольких за день — номер). Файл данных — с тем же
  суффиксом.
- Новая версия строится с нуля из файла данных. Что было отвергнуто читателем, в новую версию
  не переносится и не оставляется мёртвым кодом.
- Принятая версия и её файл чисел сохраняются вместе. Квартальные и годовые сводки собираются
  из этих файлов: прошлые версии не удаляются и не переименовываются.

## Вёрстка

- Кодировка UTF-8; `<meta charset="UTF-8">` первым в `<head>`.
- Числа в одном шрифте; декоративный шрифт только в заголовках, а заголовки без цифр: часть
  начертаний рисует цифры иначе.
- Неразрывный пробел в числах — U+00A0.
- Графики — векторные, с `viewBox`; широкие лежат в контейнере с горизонтальной прокруткой.
- Каждая ячейка карты или столбец графика: номер, имя или значение; номер совпадает с номером
  в списке под графиком. Подсказка при наведении и при касании: имя, значение, доля.
- Светлая и тёмная темы через переменные цвета; фон страницы задан явно.
- Ширина телефона: боковые поля 16 пикселей, страница не прокручивается вбок.
- Доступность: цвет не единственный носитель смысла (пунктир, форма маркера, подпись).

## Выпуск

1. Пересобрать штатной командой.
2. Повторная сборка, побайтное сравнение.
3. Проверки из `SKILL.md`.
4. Независимая проверка содержательного выпуска: другой человек или агент со свежим
   контекстом получает точный набор файлов и данные, а не пересказ.
5. Только после этого версия показывается читателям.
